# C-GEAR implementation evidence map

The stable implementation name `genetic_budgeted_calibrated` denotes C-GEAR in this repository. This note maps method features to current source and diagnostic evidence; it does not redefine or extend the method.

| Verifiable feature | Source evidence | Diagnostic evidence |
| :--- | :--- | :--- |
| Genetic candidate search | [`generate_calibrated_candidates`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L159) defines structural fitness, diverse initialization, tournament selection, set crossover, add/remove/replace mutation, elitism, and diversity-aware environmental selection. [`build_calibration_shortlist`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L779) retains global-GA and non-GA representatives for calibration. | C-GEAR `terminal.log` entries identify `selected_source=calibrated_global_ga`; exact event sources are preserved in [`cgear_active_rank_trajectories.csv`](cgear_active_rank_trajectories.csv). |
| Greedy anchor | The original threshold/tie Greedy set is formed in [`RankAllocator.increase_to_target_rank`](../../loralib/loralib/increlora.py#L1875), passed into C-GEAR by [`_increase_calibrated_rank`](../../loralib/loralib/increlora.py#L1607), and validated/repaired with bounded neighborhoods in [`generate_calibrated_candidates`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L355). | Logs distinguish `calibrated_greedy_anchor`, `calibrated_greedy_neighborhood`, and `calibrated_global_ga`. |
| Adaptive event size | [`allowed_event_rank_sizes`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L42) returns all legal sizes, and the real event commits the selected cardinality in [`_increase_calibrated_rank`](../../loralib/loralib/increlora.py#L1773). | Logged positive event sizes range from 1 to 5 in the trajectory CSV. |
| `k = 0` no-growth option | The empty chromosome is registered in [`generate_calibrated_candidates`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L474); [`score_virtual_candidate`](../../NLU/src/transformers/calibrated_rank_calibration.py#L406) scores it without model forwards. | Exact `calibrated_zero_rank` events are preserved in the trajectory CSV. |
| Training-only calibration | [`Trainer._prepare_rank_allocator_calibration_batches`](../../NLU/src/transformers/trainer.py#L596) collates deterministic indices only from `train_dataset`; [`score_virtual_candidate`](../../NLU/src/transformers/calibrated_rank_calibration.py#L406) uses paired training batches A/B for gradients and held-out fold loss. | Versioned C-GEAR `rank_pattern.json` records the training dataset fingerprint and exact calibration indices. |
| Candidate snapshot and restoration | [`VirtualCalibrationSnapshot`](../../NLU/src/transformers/calibrated_rank_calibration.py#L93) captures parameters, gradients, flags, buffers, modes, optimizer/scheduler state, and RNG, and virtual scoring restores in `finally`. [`stateless_adamw_update`](../../NLU/src/transformers/calibrated_rank_calibration.py#L282) does not advance real optimizer state. | Regression tests exercise bitwise restoration and deterministic calibration in [`test_calibrated_budgeted_evo_allocator.py`](../../NLU/tests/test_calibrated_budgeted_evo_allocator.py). |
| Conservative calibration score | [`calibration_statistics`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L86) computes mean gain minus beta times population standard deviation. [`select_calibrated_candidate`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L994) enforces the Greedy floor, global escape gate, reliable positive gain, and cost tie-break. | Allocation logs preserve fold-derived LCB, quality-floor status, and selected source at each event. |
| Hard active-parameter budget | Exact rank costs and active counts are implemented in [`increlora.py`](../../loralib/loralib/increlora.py#L27). Candidate feasibility is enforced in [`generate_calibrated_candidates`](../../NLU/src/transformers/calibrated_budgeted_evo_allocator.py#L261), and [`RankAllocator.finalize_budget`](../../loralib/loralib/increlora.py#L2287) verifies selected and final patterns. | Every local run records `budget_ratio=0.94`; the model-free reporter verifies both selected and final counts satisfy the target. |
| Adaptive stopping and consolidation | Consecutive zero events trigger stopping in [`_increase_calibrated_rank`](../../loralib/loralib/increlora.py#L1777). [`_start_consolidation`](../../loralib/loralib/increlora.py#L1454) freezes inactive reserves. Maximum rank, remaining-rank feasibility, and the final consolidation window are checked in [`update_and_increase`](../../loralib/loralib/increlora.py#L2208). | Seeds 42–44 stop by zero-rank patience; seeds 41 and 45 stop at the mandatory consolidation window. |
| New-rank warmup | [`register_new_rank_warmup`](../../loralib/loralib/increlora.py#L1361), [`snapshot_new_rank_warmup_parameters`](../../loralib/loralib/increlora.py#L1377), and [`apply_new_rank_lr_warmup`](../../loralib/loralib/increlora.py#L1390) scale only newly activated parameter deltas. Trainer integrates this around the real optimizer step. | Configuration metadata records 25 warmup steps; regression tests verify old parameters and global scheduling are unchanged. |

Local search is disabled for these C-GEAR runs (`ga_local_search=false`); it is not the reported selection mechanism.
